# 工作台页面设计覆盖规则

此页面继承 `../MASTER.md` 的扁平化后台结构、密度和交互原则，并使用以下北京大学主题覆盖规则。

## 品牌方向

- 主色：`#8B0012`，采用北京大学标识管理办公室公布的北大红 RGB 色值；
- 工作区使用低饱和浅肉粉色背景；官方校徽沿用上一版的灰度与透明质感，以 `150px` 等尺寸紧凑铺满，全部向左旋转 `45°`；纹样从桌面内容区左上角连续展开，边缘校徽按画面自然裁切，避免在四角额外叠加造成碰撞；内容卡片保持纯白；
- 正文：`#1D2025`；次级文字：`#61666F`；分隔线：`#E4E0D9`；
- 标题使用系统宋体回退，正文使用系统中文无衬线字体，避免依赖外部字体加载；
- 使用北京大学标识管理办公室提供的官方红色校徽，保持原始颜色、比例和留白；
- 试剂和仪器卡片使用本地矢量插图，根据实际容器、内容物颜色和设备轮廓进行区分；
- 视觉风格保持克制、学术、清晰；校徽底纹沿用上一版约 4.7% 的透明度，在页面留白和卡片间隙露出，不承载信息，不拦截页面交互。

## 页面结构

- 工作台提示为“试剂使用，请及时登记。”，删除其下方说明小字；

- 桌面端采用双列布局；侧栏随页头自然上移，随后在窗口顶部吸附，并使用动态视口高度填满窗口；
- 工作台依次展示欢迎区、四项指标、库存关注、待处理事项和仪器状态；
- 860px 以下侧边栏转换为抽屉；
- 640px 以下指标改为单列，库存表格转换为卡片布局；
- 所有图标按钮提供 `aria-label`，交互控件保留清晰焦点状态；
- 遵循 `prefers-reduced-motion`，关闭非必要过渡动画。
- 分区切换使用 520ms、24px 位移与淡入；各分区的内容组在上下滚动进入可视区时轻微滑入，使用浏览器原生滚动，不拦截滚轮。正文在动画结束或被取消后立即保持完整可见。
- 校徽印花背景静止；系统开启减少动态偏好时，停用内容动效并取消正在播放的动画。
- 左上角校名沿用北京大学官网原始书法图片，通过 CSS 显示校名区域；校名下方的“实验室管理系统”沿用 `909706b` 删除前的样式：12px 常规字重、次级灰色、字间距均匀加宽至与上方 141px 校名两端对齐，上下相距 3px，右侧主标题保持原有 24px 宋体样式，名称为“实验室台账管理平台”，删除标题下方的说明小字；页头保持至少 124px 的高度，维持顶部留白。
